# Case 09 — mobility-reported


**mode:** the measured quantity; zeta computable per model


## 1. Why this case

Sixteen of this paper's thirty-two rows report electrophoretic mobility directly, the quantity an instrument actually measures before any model converts it to a zeta potential. Because the raw observable is on the page, recovering zeta only needs the conversion model and, where that is missing, an interval rather than a single number -- the opposite situation from a paper that prints an already-converted zeta and never says which model produced it. That is also why this case's own lookup question below asks about a mobility row: it is the number this paper actually measured.
