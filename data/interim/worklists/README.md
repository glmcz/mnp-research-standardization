# Work lists

Preserved from the 2026-09-13 run, which kept them in an ephemeral session scratchpad. Most
were deleted before they could be recovered; what survives is here.

| file | what it is |
|---|---|
| `nonumber.txt` | the 372 papers that mention zeta but print no value the scanner finds |
| `nonumber_all_chunks.txt` | the same list as actually chunked across workers |
| `nn_last.txt` | the tail of that wave, after the main chunks |

The main corpus-sweep work lists (batches 000–027, `rem_*`, `nx_*`, `fin_*`) are **lost** —
they existed only in the scratchpad. They are regenerable from the pipeline
(`extract todo --with-values`) but the exact chunking that produced each record is not.

See `docs/ARCHITECTURE_PLAN.md` §2 for why nothing should live outside the repo again.
