What a research audience should carry home

The room is PhD students and researchers: some measure, some model, some build tools. Nanoplastics is the case study; these four patterns travel to any field, and every act should point at one of them. Explain each the way Feynman would: the picture first, then the mechanism, then what you do not know.

Absence is a value

A field the source never states is stored as “not reported”, never filled with a plausible default. Then you can count the gap instead of hiding it, and the gap is rarely random.

Claims with addresses, decisions in code

The agent returns a value, a verbatim quote and the line it sits on. Code checks it and makes every decision after that, so nothing rests on trusting the agent.

Compare a thing with itself

A bead before and after aging, a model tested on papers it never saw, the same tow found under two studies. Pairing removes everything the two sides share, so a small effect becomes visible.

Validators create pressure

A check that flags correct values teaches agents to delete them. A flag may add doubt; it must never remove evidence.
