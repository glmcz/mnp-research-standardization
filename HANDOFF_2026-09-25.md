## 3. The dataset form, as explained

**v0 exists:** `out/release/`, built 2026-09-18 by `mnp.report release`.

| file | reader | why |
|---|---|---|
| `dataset.parquet` | engineer | pandas/duckdb, 1 890 rows × 40 columns |
| `dataset.jsonl` | agent | one object per line, streamable, fits a tool response |
| `schema.json` | engineer, validator | nested pydantic record: study, size_range, surface, environment, provenance |
| `DATASET_CARD.md` | scientist | every statistic computed at build time |

One row is one measurement. The 40 columns fall into 7 groups: study, measurement, particle,
conditions, absence, evidence, provenance. Three rules carry the design:

1. **Absence is a value.** `*_reported = false` is a positive claim. It is never imputed.
2. **Every number points back to the paper**: a verbatim quote and line-hash ids.
3. **The card computes its own numbers**, and refuses to build if the stats disagree with the
   table.

**"Final" is v0 plus three layers:**

1. Confidence-tier columns (`ideas.md` §5): deterministic backing, cross-family agreement,
   human κ.
2. A comparability layer. Comparability is a relation over pairs, and today it exists only as
   code in `src/mnp/eval/comparability.py`.
3. A query layer for agents: cell D now, an MCP server later (`docs/ARCHITECTURE_PLAN.md` §9).

**Gap found, not fixed.** The release has **no column for whether the zeta conversion model
was reported**, although that is the second headline (93,2 % of papers omit it). The only
`model` column is the extraction LLM, and a scientist will read "model" as
Smoluchowski/Hückel. Proposed, not agreed:

- add `conversion_model_reported: bool`
- rename `model` → `extractor_model`

Both touch the schema, the release and the card, and the rename breaks any consumer.

## 4. Harmonisation, in five lines

Full version: `docs/2026-09-25-rao-harmonization-notes.md`.

- A correction is `f(value, protocol parameters)`. If a parameter is missing, the output is an
  **interval**. Filling a default instead moves comparable pairs from 16 to 81 624.
- The repo already has two pieces: D3 (Koelmans alignment) and `ek/` (mobility ↔ zeta).
- D3 measured that alignment removes under one decade of 8,26, with the IQR unchanged. That
  result is confounded, because every study measured a different sample.
- Testing needs same-sample data: interlab studies, spike recovery, within-paper comparisons.
- Proposal: a **zeta interlab**, the cleanest possible test. It needs wet labs, and prior art
  has not been searched.
