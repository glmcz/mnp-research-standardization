## 2. Findings

### Datasets (P7, pre-registered)

- **P7a, supported.** NOAA's pooled ocean-water median rises ×94 from 2000–04 to 2020–24, with
  no study in both periods. Inside Law et al. 2010's own series it is flat (ρ −0.02), which is
  the result the paper reported.
- **P7b, refuted.** Two of five long series rise ×10 or more:
  - the North Pacific gyre (×259), where a published rise exists;
  - Law et al. 2014 (×10.3), whose rise is ×5.3 inside its own accumulation zone, because later
    cruises sampled that zone more.

### Other dataset findings

- **Held twice.** The duplicate check, run blind, flags 5 study pairs in NOAA's database,
  including the 171 Reisser/Eriksen tows. Two of the pairs have identical shared values.
- **Same place.** Independent same-method studies within 50 km and a year differ by a median of
  ×3.3, and by ×17.7 for one pair in ten.

### More datasets: the search agent (Martin: "more datasets than NOAA")

- **Funnel:** 1 132 DataCite hits, 711 distinct, 700 on topic. Claude triaged them; a rule picked
  272 to open; code found 12 usable, 16 partial and 136 with no public file API.
- **Joined the table:** five PANGAEA sets. EMODnet trawls and the Fu 2023 air compilation were
  added by hand. The table now holds 26 552 records from 11 datasets.
- **Not joined:**
  - two flagged as overlapping NOAA;
  - three already in the table;
  - one macro-litter set;
  - the global mangrove set (Dataverse, 154 rows), still unread, the next to add;
  - PANGAEA 986752, whose per-sample abundance column is ambiguous.
- **Across databases, 100 km, any year:**
  - 57 EMODnet–NOAA pairs, a median ×1.5 apart (caveated, 330 vs 333 µm).
  - 13 NOAA–990052 pairs refused, ×61 944 apart: a 10 µm ship pump with no stated upper limit.
  - Pooled without the guard, one pair in ten would read ×29 388.
- **Not one PANGAEA find states an upper size limit.** Completeness now reports `size_max_um`.

### Aging (P11, 2026-10-24; the reviewer's idea B, second axis)

- 77 aged zeta values in 20 papers; only 7 papers set an oxidatively aged particle against its
  own virgin form in the same liquid.
- **P11a: partly.** 4 of 7 papers more negative, 2 less, 1 unchanged; median −4.7 mV
  (−11.7 to +0.4).
- **P11b: partly.** Unpaired, the interval is ×1.6 as wide, not the predicted ×2.
- Between papers, virgin PS spreads 25 mV (IQR), so aging's ~5 mV shows only paired.
- PMC12475273 prints its aged and virgin values swapped between Methods and Discussion.
- With the 5 mm rule, 4 NCEI–990052 pairs (150 µm net, 10 µm pump) are caveated, not refused.
  They stay ×22 apart after the most generous window conversion.

## 5. Lessons from this session

- **The scratchpad was wiped between turns, twice.** Keep helpers that must survive in the repo.
- **A bulk `str.replace` silently did nothing** after `ruff format` had rewrapped the text.
  Assert the count before every scripted replacement.
- **Don't name a pandas column `flags`:** `DataFrame.flags` is a pandas attribute, so `t.flags`
  returns the attribute. Use `t["flags"]`.
- **A planner given a free-text argument wrote prose.** Type the argument domains (`Literal`),
  show the allowed values in the registry, and validate before running.
- **A new dataset moved two hybrid truths inside their tolerance** (S1 3.27 → 3.25), and no test
  noticed. The between-study summaries now stay inside NCEI, and a test requires the committed
  question file to equal what the sources build today.
- **A pooled cross-dataset median hid a ×62 000 window gap.** Guard first, then the ratio. A
  refused pair is shown, but never averaged in.
- **Reading the output finds what tests do not.** Listing P11's pairs found O3 not read as ozone,
  and a salt series pooled across its levels. The verdicts did not change, but only reading
  showed it.
- **A guard that caveats must still say how much is left.** With the 5 mm rule, four pump pairs
  passed as "caveat" while ×22 apart after conversion. Dropping disagreeing pairs would bias
  toward agreement; report the residual instead.
- **A DOI's digits matched a truth value** ("10.1021" against 10.34). Strip DOIs before
  extracting numbers for grounding.
